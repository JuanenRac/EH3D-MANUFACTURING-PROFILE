# EH3D-MANUFACTURING-PROFILE: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Profiles for machines of other makers | The first profiles are for the machines of the author's workshop | the first profile format is accepted |
| Reading the machine files of the server | The files have not been read and their fields are not mapped to the units of a profile | the mapping is written and agreed with the server |
| Versions of a profile and a way to cite them | The hash cites one content; a version needs a rule about what a new version may change | the first records cite a profile |
| A window to edit a profile | The command line and a JSON file are enough to check the model first | the model of the profile is accepted |
| A task kind for the server | The server has no kind of task for a profile yet | the server accepts tasks from the engines |
